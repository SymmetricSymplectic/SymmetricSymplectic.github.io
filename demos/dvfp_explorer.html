How to read the added examples

One dimension: the left plot shows cellwise measured drift or diffusion against the known infinitesimal function and the finite-lag conditional target. Select “Sampling density” to see the distribution of starting states. The right plot evolves a localized density on Voronoi intervals; orange markers indicate signed face flux. All parameters are dimensionless and fixed per preset; sampling lag, sample count, mesh size and seed remain adjustable.

Sampling is explicit: the 1D examples use independent one-step pairs from a triangular design distribution on a bounded interval. They are not one long stationary path. This ensures coverage for nonstationary Brownian motion and GBM. These pairs identify conditional moments, but their histogram is a design density, not a stationary law. The 2D models use time-ordered trajectories.

Variable diffusion: GBM uses D(x)=0.125x² and CIR uses D(x)=0.5x. The solver retains the full difference Dⱼρⱼ−Dᵢρᵢ in the paper’s flux; replacing this by an averaged D times a density difference would solve the wrong Itô equation.

Sampling schemes: Brownian motion, OU, GBM and CIR use exact transitions. CIR has κ=θ=σ=1 and four noncentral chi-square degrees of freedom; it can therefore be sampled as a scaled sum of four squared independent normals, with one shifted normal. This uses the transition-law representation discussed by Malham and Wiese, Chi-square simulation of the CIR process and the Heston model. Double-well observations use Euler–Maruyama substeps no larger than 0.001; their finite-lag targets are not asserted to be exact.

Boundaries: all forward simulations impose reflecting outer boundaries. Positive models use [0,3]; real-valued 1D models use [−3,3]. The selected CIR parameters satisfy 2κθ≥σ², so zero is inaccessible for a positive starting value in the original SDE; GBM also stays positive. Reflecting truncation at the upper boundary is artificial. These bounded-domain evolutions are not the unrestricted GBM/Brownian transition laws. The 1D reduction of the paper’s method has face measure L=1 and cell volume equal to interval length.

Diagnostics: drift RMSE is sample-count weighted. For models with exact transitions, its target is the average conditional finite-lag drift over the actual starts in each cell. Diffusion targets average the point-conditioned variance/(2Δt); measured residual variance additionally contains within-cell variation of the conditional mean. The 1D pooled diffusion estimate uses N−K degrees of freedom. No sparse cells are dropped.

Original method, equations, and numerical limits (rotating OU)

The example is dZ = (−γI + ωR)Z dt + √(2D) dW, with γ = 0.8, D = 0.3 and R(x,y) = (−y,x). Its stationary law is N(0,(D/γ)I), independent of ω; its continuum stationary current is ωRzρ. Drift arrows in the left plot are not probability-current arrows.

Exact synthetic observations. One stationary trajectory is sampled with Zₙ₊₁ = MZₙ + √q ξₙ, M = exp(−γΔt)Rot(ωΔt), q = (D/γ)(1−exp(−2γΔt)), and independent standard normal ξₙ. The same seed makes each run reproducible. Different rotations regenerate the path and mesh; they have the same stationary law, not identical samples.

Adaptive geometry. Seeded mini-batch k-means selects representative centers from the trajectory; each center is snapped to an observed starting state. Voronoi polygons are constructed by exact half-plane clipping (up to floating-point roundoff). Their shared interior faces define the Delaunay adjacency. The rectangle encloses all starting observations with a margin. All cells are kept to preserve domain coverage; cells with fewer than 30 increments are reported rather than silently removed.

ρ̂ᵢ = nᵢ/(NAᵢ)
v̂ᵢ = mean(ΔZ | cell i)/Δt
D̂ᵢ = mean[(ΔZ − v̂ᵢΔt)(ΔZ − v̂ᵢΔt)ᵀ | cell i]/(2Δt)

The full symmetric empirical covariance tensor is computed. For this isotropic example the forward solver uses its scalar projection Dᵢ = tr(D̂ᵢ)/2. This is a stated modeling restriction: anisotropic problems, including the paper’s damped oscillator, require a different flux rule. Cellwise residual moments use the paper’s 1/n convention; the displayed pooled scalar estimate uses an N−K degrees-of-freedom correction. Within-cell drift variation still biases diffusion upward.

aᵢⱼ = ((vᵢ+vⱼ)/2) · (sⱼ−sᵢ)/dᵢⱼ
Fᵢⱼ = Lᵢⱼ [ max(aᵢⱼ,0) pᵢ/Aᵢ + min(aᵢⱼ,0) pⱼ/Aⱼ
                  + (Dᵢ pᵢ/Aᵢ − Dⱼ pⱼ/Aⱼ)/dᵢⱼ ]
pᵢ′ = −Σⱼ Fᵢⱼ,   Fⱼᵢ = −Fᵢⱼ

Conservative and positive. Each interior face is updated once with equal and opposite mass transfers; outer faces have zero normal flux (reflecting boundary). With rᵢⱼ = Lᵢⱼ[max(aᵢⱼ,0)+Dᵢ/dᵢⱼ]/Aᵢ ≥ 0, explicit Euler uses h ≤ 0.9/maxᵢΣⱼrᵢⱼ. Thus each step preserves mass and nonnegativity in exact arithmetic. No clipping of negative probabilities and no mass renormalization are used during evolution.

Interpretation. The localized initial packet is a cell-area-weighted Gaussian sampled at mesh sites, normalized once. The forward calculation is a first-order upwind approximation on a bounded domain. Mesh diffusion, reflecting boundaries, sampling noise, and finite-lag bias mean its stationary density/current need not equal the whole-plane analytic solution. The “known model” control isolates sampling error but retains discretization and boundary error. This demo is an implementation, not a reproduction of the paper’s 20-seed tables or a convergence proof. Optional SINDy is not implemented.
