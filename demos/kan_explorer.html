Laboratorio / Aprendizaje de funciones

¿Y si las conexiones aprendieran curvas?

Una red tradicional aprende pesos y combina activaciones fijas. Una red de Kolmogorov–Arnold (KAN) aprende funciones en sus conexiones. Entrena aquí dos modelos pequeños para aproximar la misma función y observa cómo construyen su respuesta.

01 / Red tradicional · MLP

Cada neurona suma entradas ponderadas, añade un sesgo y aplica una función fija, aquí tanh. El entrenamiento modifica pesos y sesgos.

hⱼ = tanh(wⱼx + bⱼ)
ŷ = b₀ + ∑ⱼ aⱼhⱼ
x → 8 neuronas tanh → suma → ŷ

02 / Red KAN

Una capa calcula x′ⱼ = ∑ᵢ φⱼᵢ(xᵢ): transforma cada entrada con una función aprendida y suma los resultados. Varias capas componen esas transformaciones.

x′ⱼ = ∑ᵢ φⱼᵢ(xᵢ)
En este ejemplo mínimo: ŷ = φ(x)
x → curva φ aprendida → ŷ
La idea matemática: del teorema a una red entrenable

El teorema de representación de Kolmogorov–Arnold establece que una función continua f sobre [0,1]ⁿ puede escribirse como una suma finita de composiciones de funciones continuas de una variable:

f(x₁,…,xₙ) = ∑q=02n Φq(∑p=1n ψq,p(xp))

Esta representación inspira las KAN, pero no garantiza que una red pequeña con splines encuentre una solución exacta ni que su entrenamiento sea más rápido. En la práctica se eligen una arquitectura y una familia finita de funciones, y se ajustan sus parámetros con datos.

Aquí usamos el caso unidimensional más sencillo: una KAN [1,1], con una sola conexión. φ es una spline lineal: interpolamos entre alturas aprendidas en nodos equidistantes. Es una simplificación didáctica; las KAN del artículo original usan una parametrización con B-splines y una función base. Este ejemplo no explora la composición multivariable de una KAN profunda.

El ECM es el promedio de (predicción − referencia)². Entrenamiento: 64 muestras, con el ruido elegido. Evaluación: 257 puntos distintos, sin ruido, dentro de [−1,1]; no se usan para actualizar los modelos.

Dentro de la KAN: alturas aprendidas

Cada punto es un parámetro. Entre dos puntos, la salida es una interpolación lineal; el efecto de mover una altura es local.

Dentro de la MLP: contribuciones

Cada curva representa aⱼ tanh(wⱼx + bⱼ). Su suma, más el sesgo de salida, produce la predicción. Los colores se repiten entre neuronas.

Igualar parámetros y épocas no iguala el costo de cálculo ni favorece siempre al mismo modelo. Este problema de una variable permite a la spline ajustar localmente los datos; una MLP tiene otra forma de generalizar. Un resultado aquí no demuestra superioridad general de las KAN.

Protocolo y sugerencias para explorar

Ambos modelos usan Adam con tasa 0.01, β₁ = 0.9, β₂ = 0.999 y ε = 10⁻⁸, sin regularización, hasta 3 000 épocas. La MLP tiene arquitectura [1,H,1] y 3H+1 parámetros. La KAN [1,1] tiene 3H+1 alturas en nodos fijos. Se inicializan por separado con un generador determinista; reiniciar conserva los datos y la inicialización.

El tiempo acumula únicamente las actualizaciones de cada modelo, excluye gráficas y evaluación, y depende del navegador y del equipo. La curva de error se muestrea cada 10 épocas. La evaluación cubre el mismo intervalo: no mide extrapolación.

Prueba «Valor absoluto» para observar la esquina; «Onda con detalle» para comparar capacidad; y ruido 0.30 para distinguir el ajuste de las observaciones de la recuperación de la función sin ruido. Compara varias semillas antes de sacar conclusiones.
